# T-002 — linkcheck: skip files that are not UTF-8, pin the output order

## Goal

A writer who runs the checker over a folder holding one file that is not valid UTF-8 gets the report for every
other file and a message naming the skipped file, instead of a traceback that hides the rest. The task also closes
the two gaps the T-001 verdicts left open: no test pinned the sort order of files in a folder, and none pinned the
order of two links on one line. The checker's behaviour for valid files does not change.

## Spec

[`example/linkcheck/SPEC.md`](../example/linkcheck/SPEC.md): AC4 and AC5, the Interface line on files that are not
valid UTF-8, and the Exit status line.

## Owns

The path globs the worker may change. They must equal the `owns` the task was created with in the store.

- `example/linkcheck/**`

## Acceptance criteria

Number each criterion and say how it is checked, by a named test or by a command and its expected output.

1. AC4: A file that is not valid UTF-8 is skipped with one line on standard error, the other files are still
   checked and reported, and the exit status is 2. Checked by: `test_file_that_is_not_utf8_is_skipped_and_named`
   in `example/linkcheck/tests/test_linkcheck.py`, with the fixture and exact outputs of SPEC AC4.
2. AC5a: Two broken links on one line are reported in the order they appear in the line. Checked by:
   `test_links_on_one_line_follow_their_position`.
3. AC5b: Files of one directory are reported sorted by path, with a fixture whose sorted order differs from the
   order `Path.rglob` returns. Checked by: `test_directory_files_are_reported_in_sorted_order`; the worker shows in
   a progress note that the test fails against a copy of the checker without `sorted(...)`, made outside the
   repository.
4. AC1 to AC3 and the edge case still hold: every existing test in `example/linkcheck/tests/` passes unchanged.

## Edge cases

- A folder where the only file is not valid UTF-8: standard output is empty, standard error has the one line, and
  the exit status is 2, not 0.
- A file passed directly as a PATH that is not valid UTF-8 is named as given, like any other file.

## Out of scope

- Any encoding other than UTF-8, guessing an encoding, or a byte-order mark.
- Files that cannot be read for other reasons (permissions, a folder named `*.md`).
- Any change to AC1 to AC3, the output format of broken links, or the skipped targets.
- Any change outside `example/linkcheck/`, including the gate itself.
